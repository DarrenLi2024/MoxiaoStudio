# 闲心子墨内容适配器

## 边界

`@moxiao/xianxinzimo-adapter` 是墨校台与闲心子墨之间的防腐层。它读取闲心子墨现有 `works.json`、五卷 `readings*.json`、`pronunciations.json`、`natural-readings.json`、音频和图片资源，不让 iOS Bundle 结构渗入文枢领域模型。

适配器默认只读源仓库。它可以把资源转换为 `XZM-EW 0.1` 工作区，也能把工作区重新分派为闲心子墨原有资源文件；正式回写只能先生成独立暂存包、审核差异、运行闲心子墨自身门禁，不能直接覆盖 App 资源。

## 内容包

`XZM-XIANXIN-CONTENT 1.0` 包含：

- `manifest.json`：格式、内容哈希、数量、每个资源文件的哈希与字节数。
- `resources/`：作品、笺读分卷、校音和朗读轨定义。
- `media-manifest.json`：音频和图片的路径、哈希、字节数与权利复核状态。
- 可选 `media/`：只有显式使用 `--include-media` 时才复制媒体本体。

内容包不写入源仓库绝对路径。媒体在没有读取并核验项目权利台账前统一标为 `requires-review`，不能因文件存在就推定可出版。

## 使用

只读审计并执行完整语义往返：

```bash
pnpm audit:xianxinzimo "/闲心子墨仓库绝对路径"
```

生成不含媒体本体的交付包：

```bash
pnpm pack:xianxinzimo "/闲心子墨仓库绝对路径" "artifacts/xianxinzimo-content"
```

只有需要离线完整迁移并已经确认资源权利时，才在末尾添加 `--include-media`。

## 2026-08-11 实库基线

本轮只读扫描得到 233 条作品记录、132 篇外置笺读、42 条语境校音、10 条朗读轨、10 个音频文件和 65 个图片文件。源资源到文枢工作区再还原为闲心子墨资源的语义比较为零差异；同时闲心子墨自身的正文结构、校音和自然朗读审计均通过。

以上数量是本次工作树快照，不写成永久业务常量。后续每次迁移必须重新扫描并以内容哈希为准。
