# ADR 0007：AI 建议永不直接改写活母本

- 状态：已接受
- 日期：2026-08-22

## 背景

文学文本、作者创作意图、系年与笺读具有不可替代的人工判断。云模型可能产生幻觉，且正文可能包含未公开内容。把模型输出直接写入母本会破坏现有版本、证据和人工确认边界。

## 决策

引入版本化 `AssistantRun` 与 `AssistantSuggestion` 契约。模型和本地规则只创建建议；建议只允许指向白名单字段，并保存原值、建议值、理由、置信度、证据和来源。接受建议由编辑用例校验当前值仍等于建议基线后执行；若母本已变化则产生冲突，不静默覆盖。云端连接器默认关闭，采用 BYOK、显式内容预览和本机安全存储。

## 取舍

此方案比自动改写多一步，但保留作者主权、可撤销性和审计能力。MVP2 不建设通用 Agent、向量数据库或后台自治任务；未来模型、检索与插件都只能扩展建议生产端，不能绕开同一接受门禁。
