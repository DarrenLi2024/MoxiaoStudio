# ADR-0006：采用语义成书模型与可解释编排

## 状态

已采纳，2026-08-17。

## 背景

逐篇把校勘记和版本说明拼接到正文，会混淆编辑过程与读者成品；任意 CSS 编辑又会使 PDF、EPUB 和客户端内容包产生不可控差异。单篇插图和智能编排同样需要在不污染母本的前提下复用。

## 决策

出版项目升级为版本 1.1，以 `frontMatter`、`apparatusPolicy`、`authorProfile`、`theme`、篇目媒体位置和编排提案描述成书意图。编译阶段产生带 `semanticRole` 的 Publication IR，渲染器只消费语义角色和受控样式令牌。

智能编排分为确定性排序和可解释策展。建议先保存为候选提案，只有人工应用后才更新当前出版项目的 `manualOrder`；作品母本顺序保持不变。媒体资产与出版位置分离，同一原图可在不同书稿或篇目中采用不同角色。

## 后果

- 普通读者版、学术整理本和内部审校稿可以引用同一母本。
- 跨格式内容保持一致，同时允许 PDF 与 EPUB 使用适合自身媒介的布局。
- 旧 1.0 项目必须经确定性迁移补齐默认字段。
- 语义样式比自由模板更受约束，但能获得可复现、可预检和可维护的成品。

## 备选方案

- 固定模板：实现简单，但无法满足篇目级变化。
- 自由所见即所得排版：灵活但难以保证跨格式一致、可访问性和出版重现。
- 直接把出版顺序与插图写回母本：会污染作品事实层，因此拒绝。
