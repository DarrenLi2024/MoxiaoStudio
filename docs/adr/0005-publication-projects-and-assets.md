# ADR-0005：出版项目与活母本分离

## 状态

已采纳，2026-08-17。

## 背景

同一批作品可能按系年、体裁或作者意图形成多部书稿，并使用不同封面、插图、字体和版式。如果把出版顺序或视觉配置写回作品记录，会污染母本编次，也无法可靠重现既有成品。

## 决策

引入版本化 `PublicationProject`，独立保存篇目引用、收录开关、人工顺序、筛选、资产、主题、输出目标和 `PublicationProfile`。作品与笺读仍属于活母本；书稿项目只引用稳定记录和实体 ID。导出时由两者编译出 `PublicationDocument`，随后交给声明真实能力的 PDF、EPUB 或内容包适配器。

封面、插图和字体统一进入项目资产清单，记录媒体类型、替代文字和权利状态。权利未知时阻止导出。桌面首版为了离线可移植性把有体积上限的资产数据保存在项目载荷中；后续对象存储适配器可迁移二进制内容，但不得改变资产 ID 和出版快照语义。

## 后果

- 同一母本可建立多部互不干扰的书稿。
- 调整出版顺序不会修改作品 `seq`。
- PDF、EPUB 与客户端包消费相同篇目清单和表达哈希。
- 资产权利、字体授权和适配器能力成为导出前强制门禁。
- 大体积媒体未来需要对象存储迁移；当前 12 MB 单资产和 16 MB 数据 URI 上限防止 SQLite 载荷失控。
