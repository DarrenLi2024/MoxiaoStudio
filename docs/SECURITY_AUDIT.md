# 安全审计报告

审计日期：2026-08-17。范围：桌面主进程、预加载桥、React 渲染进程、SQLite 仓储、JSON/内容适配器、出版 HTML/PDF 和依赖树。

## 已修复

### 高危

1. Electron 40.10.3 命中沙箱 iframe 导航绕过公告。已升级到修复版本 41.10.3，并重新运行依赖审计为零已知漏洞。

### 中危

1. 桌面入口缺少显式 CSP。已限制脚本、样式、连接、对象、表单和 frame 来源；出版 iframe 使用独立的无脚本 CSP。
2. IPC 入口缺少统一体积边界。已对审校包、单篇文本、批量文本和出版配置增加类型、枚举、长度及数值范围验证。
3. 窗口未显式拒绝新窗口和页面导航。主窗口及隐藏打印窗口现均拒绝 `window.open`，主界面阻止非程序化导航。
4. 大体量出版 HTML 曾通过 `data:` URL 送入隐藏打印窗口，会受到 Chromium URL 长度上限约束。现改为随机命名、权限 `0600` 的系统临时文件，打印窗口销毁后同步删除；出版 HTML 仍采用无脚本 CSP，图片和字体仅允许嵌入的 `data:` 资源。

## 当前结论

未发现明文密钥、动态代码执行、拼接 SQL、Node 集成、未沙箱渲染窗口或用户 HTML 直接注入。SQLite 查询均参数化，用户文本进入出版 HTML 前统一转义。`executeJavaScript` 只执行固定的 `document.fonts.ready` 表达式，不包含用户输入。

## 保留风险

- 本地数据库尚未做系统密钥链加密；依赖操作系统账户和磁盘加密保护。
- macOS 公开预览包依赖受控本机 Developer ID 签名与 Apple 公证；GitHub CI 尚未托管签名凭据，发行仍需核验本机生成的不可变制品。
- 自托管 Web 和远端协作尚未实现，因此认证、租户隔离、限流和远端密钥管理不在当前运行时范围。
