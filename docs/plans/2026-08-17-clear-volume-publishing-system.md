# 墨校台·澄卷出版系统实施计划

## 目标

把出版中心升级为内容边界清楚、视觉克制、跨格式一致的成书系统。校勘记、版本说明和审校说明继续保存在活母本，普通读者版不逐篇输出；书稿可以生成版权页、前言、作者简介、统计和目录，并对单篇插图、篇目编排和语义样式作项目级配置。

## LOOP 交付

1. 出版项目 1.1：旧项目迁移、编校信息策略、前置页、作者档案、统计与目录 IR。
2. 篇目媒体：一篇多图、题图/随文图/插页/尾花位置、图注、替代文字和权利门禁。
3. 智能编排：作者编定、体裁、系年、意境和混合策略；候选方案必须解释、可锁定、可撤销。
4. 语义样式：素笺雅集、青简笺读、当代清集、典藏书稿四套主题，以及标题、译文、笺注、赏析的组件变体。
5. 成书体验：书稿信息、篇目编排、前置页、样式、媒体、预检导出六步工作流；PDF 与 EPUB 共用同一 Publication IR。
6. 发行验收：类型、单元、真实 Electron、EPUBCheck、PDF、隔离生产副本、安装包、签名、公证和 GitHub 制品。

## 不变量

- 出版项目不得改写作品母本 `seq`、正文、笺读或系年事实。
- 智能分析只产生建议；低置信度意境和人物事实必须人工确认。
- 出版前言与作者简介保存生成依据和确认状态；未确认草稿不得进入正式成品。
- PDF、EPUB 与内容包必须锁定相同篇目、顺序、前置页和表达哈希。
- ISBN、出版社、责任编辑和版权归属不得推测；正式出版模式缺少必填事实时预检失败。

## 验收

- 默认成品不逐篇出现校勘记或版本说明，可选择书末汇总或内部审校稿。
- PDF 与 EPUB 均包含书名页、版权页、前言、作者简介和语义目录。
- 每篇可配置零至多幅插图，移除出版位置不删除原始资产。
- 智能编排给出理由，锁定篇目不被重排，应用结果可撤销。
- EPUB 使用相对字号与语义导航；PDF 使用精确尺寸并校验页数与结构。
- 深色、窄屏、大字体和减弱动态效果下仍可完成完整出版流程。
