# 墨校台·版式工坊实施计划

## 目标

将出版中心现有的单层 `PublicationTheme` 升级为可继承、可覆盖、可按属性锁定的语义样式矩阵。书名、篇名、诗词正文、散文正文、创作题注、今译、笺注、赏析、图注、目录及前后置页分别拥有明确样式，PDF 与 EPUB 从同一事实源生成，不再依赖视图层硬编码。

## 决策

1. `PublicationProject` 升级为 1.3，保留 `theme` 作为预设身份与旧字段兼容层，新增 `styleSheet` 与 `layoutSpecification` 作为新事实源。
2. 样式采用“基础样式 → 语义元素样式 → 目标适配”的确定性级联。属性锁定只阻止主题、全局缩放和自动布局改写，不等同于 CSS `!important`。
3. 首期锁定作用域为当前书稿项目；PDF 与 EPUB 只生成适配结果，不反向污染作者设定。
4. GB/T 788-1999 只作为开本与幅面来源，不虚构字体、行距或装帧美学规则。标准预设必须保留标准号、版本、尺寸和自定义状态。
5. 迁移后视觉必须保持：旧主题正文沿用原字号与行距，诗词正文显式迁移为原硬编码的 13pt、2 倍行距。

## 领域模型

- `SemanticStyleRole`：出版元素稳定角色。
- `StyleProperties`：字体、字号、字重、行距、字距、颜色、对齐、缩进、段距、下划线、装饰线、边框、底纹、圆角和内边距。
- `SemanticStyleDefinition`：`basedOn`、`properties`、`locks`。
- `PublicationStyleSheet`：版本、角色样式、目标适配覆盖。
- `LayoutSpecification`：标准引用、成品尺寸、对页、内外边距、栏数、栏间距、基线网格。

## 级联与锁定

1. 解析父样式并检测循环。
2. 子样式仅覆盖显式属性。
3. 主题切换按目标主题生成建议值；已锁定属性保留当前有效值。
4. 单项锁定前若属性仍来自继承，先将当前有效值固化到本角色，再记录锁定。
5. 清除覆盖恢复继承；解锁不自动删除当前值。
6. 目标适配器不支持的锁定属性必须给出预检提示，不能静默丢弃。

## 界面

样式步骤改为“版式工坊”：上方保留主题预设；主体左侧为语义元素列表，中部为元素属性检查器，右侧继续使用实时成书预览。每项属性显示继承、覆盖或锁定状态；属性旁提供锁定按钮，元素提供整组锁定与恢复继承。页面设置独立呈现标准开本、成品尺寸、对页、内外边距、栏和基线网格。

## 分批交付

### 批次一：契约与迁移

- 输出：1.3 类型、默认样式表、迁移、校验、样式解析和锁定纯函数。
- 测试：1.2 → 1.3 往返；诗词 13pt/2 倍行距保持；循环继承和非法 CSS 值拒绝。

### 批次二：渲染适配

- 输出：PDF/HTML 与 EPUB 的同源语义 CSS；取消诗词硬编码。
- 测试：修改诗词字号只影响诗词；今译、笺注、赏析相互独立；EPUB 使用相对字号并保留读者控制。

### 批次三：版式工坊与锁定

- 输出：元素选择、字体字号行距、段距、装饰线、边框、底纹、圆角、锁定与恢复继承。
- 测试：锁定正文行距后切换主题不变；解锁后可更新；重启后持久化。

### 批次四：开本与专业预检

- 输出：GB/T 引用预设、版心参数、基线网格辅助视图、适配差异预检。
- 测试：开本尺寸进入 PDF；EPUB 忽略固定页设置但明确报告；无静默降级。

### 批次五：发行验收

- 输出：文档、变更日志、桌面/窄屏/深色截图、PDF/EPUB、正式资料库隔离回归、签名公证 DMG。
- 测试：`pnpm check`、Electron E2E、EPUBCheck、安装包冷启动及 GitHub 资产摘要。

## 非目标

- 本轮不实现自由拖拽文本框、任意坐标图层或完整 InDesign 文件兼容。
- 不以 GB/T 788-1999 名义定义该标准没有规定的字体与审美规则。
- 不强制 EPUB 阅读器禁用用户字号、行距和配色设置。
