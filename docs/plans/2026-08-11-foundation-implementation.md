# 墨校台文枢 3.0 地基实施计划

## 第一批

1. 建立独立仓库、中文文档体系和可复现工具链。
2. 实现领域模型、Ontology v1、Publication IR 与渲染能力预检。
3. 实现 Electron + React 桌面工作台壳并完成构建、测试和视觉验证。

## 第二批

1. 迁移现有一卷通校读取、筛选、编辑、保存和审校状态。
2. 迁移新增、批量摄取、导入、查重、清空和删除工作流。
3. 建立 SQLite 仓储、崩溃恢复日志和语义版本快照。

## 第三批

1. 建立出版中心、分页预览和 PDF 配置。
2. 建立 ExportValidator、字形和资源权利预检。
3. 建立闲心子墨发布适配器及旧 JSON 往返验证。

## 开放阶段

完成许可证与内容清理后建立 GitHub 远端；桌面版稳定后再实现 Docker 自托管 Web，避免在本地数据模型未稳定时同时维护两套基础设施。
