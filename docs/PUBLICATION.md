# 出版中心与渲染边界

## 当前可交付能力

桌面端内置 Electron Chromium、EPUB 3 和结构化内容包三类适配器。当前实际支持：

- A4、A5、B5 与自定义纸张的分页 HTML 预览。
- 文字水印内容、透明度、角度、位置与上下层配置。
- 页眉、页脚、总页数和当前页码变量。
- Tagged PDF、嵌入字体、文件签名、结束标记、页数和异常体积验证。
- 插图替代文字、资源权利声明和乱码门禁。
- 独立多书稿项目、篇目收录、体裁多选，以及系年、意境、综合策展和作者编定排序；界面清单、目录和导出共享同一顺序，动态顺序可显式固化，智能候选带逐篇理由并支持位置锁定、应用与撤销。
- 版权页、书名页、前言、作者简介、统计与语义目录；前言和简介保留生成依据及人工确认状态。
- 自定义封面、作者照片、单篇题图、随文锚点图、独立插页、篇末尾花和项目图库复用。
- `素笺雅集`、`青简笺读`、`当代清集`、`典藏书稿` 四套主题，以及标题、译文、笺注、赏析、字体、字号、行距、段落节奏、章首留白、诗行对齐、版心宽度、主题色和章饰的受控组合；修改先实时渲染，再后台持久化。
- 可重排 EPUB 3.3 的 OPF、清单、阅读顺序、导航、正文地标、XHTML 章节、响应式 CSS、版权和基础无障碍发现元数据、图片及嵌入字体。
- 闲心子墨与 WebPub 的结构化暂存交付包、来源修订和表达哈希。

内置适配器只声明 `screen` PDF。它不会把普通 Chromium PDF 冒充 PDF/X、PDF/A 或 PDF/UA，也不会静默忽略出血、裁切标记、镜像页边距、CMYK 或字形覆盖检查。用户选择超出能力的配置时，预检必须阻止导出并说明原因。

EPUB 适配器不声明水印、页眉页脚、固定页码或印刷规格；这些 PDF 项不会进入电子书，也不会阻断 EPUB 导出。内容包适配器不声明字体嵌入。电子书仍受书名、正文、导航、资源权利、插图替代文字和字符完整性门禁约束。

## 电子书兼容配置

- `通用 EPUB 3.3`：默认配置，强调标准容器、可重排、相对字号、语义导航与保守 CSS。
- `Apple Books`：沿用通用基线，并检查封面短边 1400 像素建议；最终提交仍需按 Apple Books 当前资产指南复验。
- `中文阅读器兼容基线`：适用于微信读书等中文阅读环境的预检查，保持水平可重排、完整目录、标准清单和无平台私有 CSS。微信读书未公开完整技术提交规范，因此本名称不代表平台认证。

目标阅读器配置是验证策略，不改变作品事实。平台私有字段必须在独立适配器中加入，不能污染通用 `PublicationDocument`。

## 成书内容边界

- 校勘记、版本说明和审校说明属于编辑过程信息，默认不进入读者版，也不在每篇篇末重复出现。
- `书末附录` 只汇总校勘记与版本说明；`内部审校附录` 另收审校说明。两者都不改动活母本。
- 正式自版或出版社模式下，前言、作者简介未确认会阻止导出；内部审校稿只给出警告。
- 出版社名称、ISBN、版权归属和作者生平不得推测。出版社模式缺少出版社名称、版权页缺少权利人或插图权利/替代文字未确认时，预检失败。
- 随文插图锚点必须引用正文短句；命中后自动包含紧随标点，未命中则明确警告并确定性降级至正文后。

## 模板变量

页眉页脚支持以下变量：

- `{{bookTitle}}`：书名。
- `{{chapterTitle}}`：当前篇章标题；内置适配器当前保留为空，专业分页适配器接管后启用。
- `{{page}}`：当前页码。
- `{{pages}}`：总页数。

## 专业印刷适配

Publication IR、配置和能力声明均不依赖具体渲染器。后续 Vivliostyle 适配器负责开放排印的出血与裁切标记；出版社如要求 PDF/X-4、CMYK、输出意图或指定 RIP，必须接入明确声明这些能力的专业适配器，并用真实预检工具验证。任何适配器都必须返回能力清单、版本、预检结果与成品哈希。

## 验收

`pnpm test:e2e` 会用隔离资料库走完六步出版流程，验证智能编排、语义主题、单篇随文插图、真实 PDF 与 EPUB，并在应用重启后复核笺读持久化。`pnpm test:large-publication` 接受正式资料库的 SQLite 在线备份，只在临时 profile 中完成整卷 PDF 回归。自动验收检查文件结构和持久化链路；发布前还要用 Poppler 渲染 PDF、执行 `pnpm validate:epub "/绝对路径/书稿.epub"`，并人工观察标题、正文、题注、插图、水印、页眉页脚、分页断点和生僻字不得裁切、重叠或变成缺字方框。
