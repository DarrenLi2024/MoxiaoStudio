# 出版中心与渲染边界

## 当前可交付能力

桌面端内置 Electron Chromium 渲染适配器，`0.1.0` 已实际支持：

- A4、A5、B5 与自定义纸张的分页 HTML 预览。
- 文字水印内容、透明度、角度、位置与上下层配置。
- 页眉、页脚、总页数和当前页码变量。
- Tagged PDF、嵌入字体、文件签名、结束标记、页数和异常体积验证。
- 插图替代文字、资源权利声明和乱码门禁。

内置适配器只声明 `screen` PDF。它不会把普通 Chromium PDF 冒充 PDF/X、PDF/A 或 PDF/UA，也不会静默忽略出血、裁切标记、镜像页边距、CMYK 或字形覆盖检查。用户选择超出能力的配置时，预检必须阻止导出并说明原因。

## 模板变量

页眉页脚支持以下变量：

- `{{bookTitle}}`：书名。
- `{{chapterTitle}}`：当前篇章标题；内置适配器当前保留为空，专业分页适配器接管后启用。
- `{{page}}`：当前页码。
- `{{pages}}`：总页数。

## 专业印刷适配

Publication IR、配置和能力声明均不依赖具体渲染器。后续 Vivliostyle 适配器负责开放排印的出血与裁切标记；出版社如要求 PDF/X-4、CMYK、输出意图或指定 RIP，必须接入明确声明这些能力的专业适配器，并用真实预检工具验证。任何适配器都必须返回能力清单、版本、预检结果与成品哈希。

## 验收

`pnpm test:e2e` 会用隔离资料库生成真实 PDF。自动验收检查文件结构和持久化链路；发布前还要用 Poppler 渲染页面并人工观察：标题、正文、题注、水印、页眉页脚、页码、分页断点和生僻字不得裁切、重叠或变成缺字方框。
